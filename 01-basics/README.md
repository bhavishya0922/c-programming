# 01-basics — Foundational C Syntax & Operators

> Practical C programs illustrating core systems programming concepts.

## Programs List

| File | Concept / Description | How to Compile |
|---|---|---|
| `01_hello_world.c` | Standard output with printf and main entry point | `gcc -Wall -Wextra 01_hello_world.c -o run && ./run` |
| `02_data_types_sizes.c` | Inspecting data types and memory sizes using sizeof operator | `gcc -Wall -Wextra 02_data_types_sizes.c -o run && ./run` |
| `03_arithmetic_operators.c` | Arithmetic operations, modulus, and operator precedence | `gcc -Wall -Wextra 03_arithmetic_operators.c -o run && ./run` |
| `04_user_input_scanf.c` | Reading formatted input using scanf and address-of operator | `gcc -Wall -Wextra 04_user_input_scanf.c -o run && ./run` |
| `05_type_casting.c` | Implicit type coercion vs explicit type casting | `gcc -Wall -Wextra 05_type_casting.c -o run && ./run` |
