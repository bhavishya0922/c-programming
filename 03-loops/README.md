| File | Concept / Description | How to Compile |

| `02_while_reverse_number.c` | While loop extracting digits and reversing integer | `gcc -Wall -Wextra 02_while_reverse_number.c -o run && ./run` |
| `03_pattern_printing.c` | Nested loops printing triangular and pyramid star patterns | `gcc -Wall -Wextra 03_pattern_printing.c -o run && ./run` |
| `04_armstrong_number.c` | Armstrong number check using power of digits | `gcc -Wall -Wextra 04_armstrong_number.c -o run && ./run` |
