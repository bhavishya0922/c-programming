# 07-pointers — Memory Addresses, Dereferencing & Arithmetic

> Practical C programs illustrating core systems programming concepts.

## Programs List

| File | Concept / Description | How to Compile |
|---|---|---|
| `01_pointer_basics.c` | Pointers declaration, address-of operator, dereferencing | `gcc -Wall -Wextra 01_pointer_basics.c -o run && ./run` |
| `02_swap_call_by_reference.c` | Call-by-reference swapping with pointer arguments | `gcc -Wall -Wextra 02_swap_call_by_reference.c -o run && ./run` |
| `03_pointer_arithmetic.c` | Pointer increment and iterating arrays through addresses | `gcc -Wall -Wextra 03_pointer_arithmetic.c -o run && ./run` |
